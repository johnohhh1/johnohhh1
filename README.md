# Hi, I'm John 👋

I build small tools that scratch my own itch: getting desktop AI apps running on Linux, poking at cheap Allwinner hardware, fire-service tech, and the odd game. They're all free to use. Issues and pull requests are welcome on any of them.

## 🐧 AI apps on Linux

| Repo | What it does |
|---|---|
| [claude-desktop-ubuntu](https://github.com/johnohhh1/claude-desktop-ubuntu) | Builds a .deb of Claude Desktop for Ubuntu, with Wayland support |
| [chatgpt_desktop_ubuntu](https://github.com/johnohhh1/chatgpt_desktop_ubuntu) | Turns the ChatGPT desktop MSIX into a working .deb for Ubuntu 26.04 |
| [codex-ubuntu](https://github.com/johnohhh1/codex-ubuntu) | Codex desktop (Electron) packaged for Ubuntu |
| [kimi-app](https://github.com/johnohhh1/kimi-app) | Native Kimi (Moonshot AI) desktop app for Ubuntu 26.04+, built with Pake/Tauri |
| [ollama-webchat-ubuntu](https://github.com/johnohhh1/ollama-webchat-ubuntu) | Linux (GTK3 + WebKit2GTK) port of the official Ollama desktop app |
| [comfyui-desktop-port-linux](https://github.com/johnohhh1/comfyui-desktop-port-linux) | Ubuntu-focused port of the official ComfyUI Desktop app |
| [ollama-code](https://github.com/johnohhh1/ollama-code) | Rewires the Copilot VS Code extension to use local Ollama models |
| [portal_use](https://github.com/johnohhh1/portal_use) | MCP file-system tool for Claude Desktop on Wayland |
